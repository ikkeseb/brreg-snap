# Icons

PNG icons consumed by `manifest.json`:

- `icon-16.png` (16×16)
- `icon-32.png` (32×32)
- `icon-48.png` (48×48)
- `icon-128.png` (128×128)

Generated by `scripts/generate-icons.mjs` — downsamples the brand
mark `brand-b.png` (1024×1536 RGBA) to each manifest size using a
box-filter area average. That source is gitignored under `docs/` and
exists only on the machine that holds it; a fresh clone can't
regenerate the icons. Re-run after editing the brand mark:

```
node scripts/generate-icons.mjs
```

Requires `pngjs` (devDep).

# AMO submission kit — brreg-snap {{version}}

Generated by `pnpm release {{version}}` from `docs/amo-submission.md`,
`PRIVACY.md` and `CHANGELOG.md` § [{{version}}], which stay canonical:
fix text there, not here. Only the release notes are written by hand.
The whole flow: `docs/release.md`.

## Recipe

1. Write both release notes below over their TODO lines, then run
   `pnpm release {{version}} --tag` (it refuses while a TODO is left)
   and push what it prints.
2. When the GitHub Release `v{{version}}` exists, run the **Publish to
   stores** workflow (version `{{version}}`) and approve it in the
   `store-publish` environment. It uploads `brreg-snap-{{version}}.zip`
   and `brreg-snap-source-{{version}}.zip` to AMO with the release notes
   and the reviewer notes below, then tags `amo-submission-{{version}}`.
3. By hand, and only if this release changed them: the listing text and
   the privacy policy on the AMO edit page (sections below), per
   `docs/release.md` § What stays manual.

## Release notes

Plain text, a few short lines per locale: what changed for the user.
AMO shows them on the version history page. Line breaks inside a
paragraph are joined when sent; a blank line starts a new paragraph.

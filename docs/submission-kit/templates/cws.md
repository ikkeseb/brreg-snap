## Recipe

1. When the GitHub Release `v{{version}}` exists, run the **Publish to
   stores** workflow (version `{{version}}`) and approve it in the
   `store-publish` environment. It uploads
   `brreg-snap-chrome-{{version}}.zip`, submits it for review, then
   tags `cws-submission-{{version}}`. CWS has no per-version release
   notes field.
2. By hand, and only if this release changed them: the store listing
   description and the privacy practices tab in the Developer
   Dashboard (sections below). Show Seb one line first: version,
   store, what changes. The privacy policy URL serves `PRIVACY.md` on
   `main`, so it updates when `main` does.

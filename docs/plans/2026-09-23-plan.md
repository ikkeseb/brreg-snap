## Decisions (Seb, 2026-09-23)

- **North star: real, active users.** brreg-snap is a trust tool: it
  answers «who is behind this site, and are they OK?» — not just «look
  up a company».
- **Wrong data ships as a patch ASAP (v1.3.1), and a gate must catch
  the next API drift.**
- **Honest data declarations.** The visited site's domain is sent to
  brreg; both stores and PRIVACY.md say so plainly («sent only to the
  public registry, never to the developer»).
- **`sebastian@nuez.no` is the only public contact**, including the CWS
  developer contact (live listing shows a personal gmail today).
- **Store rollout is agent-driven** via Seb's logged-in browsers (Chrome
  on the Windows PC; AMO + CWS) once gates and verification pass. Upload
  only CI release artifacts. Before pressing submit, show Seb one line:
  version, artifact → store, listing changes.
- **AGENTS.md becomes the canonical agent file**; CLAUDE.md imports it.
